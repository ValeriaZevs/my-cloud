# MyCloud - Облачное хранилище файлов

Полноценный сервис облачного хранения данных, разработанный в рамках дипломного проекта. Проект использует Production-архитектуру: единый сервер на базе Django раздает как статические файлы (оптимизированную сборку React), так и обрабатывает API-запросы.

## Технологический стек

* **Frontend:** React 18, Redux Toolkit, React Router, Native Fetch API (с глобальным перехватчиком JWT).
* **Сборщик:** Самостоятельно настроенный Webpack (Babel, CSS/Style Loaders).
* **Backend:** Python 3.12, Django 6.0, Django REST Framework (DRF).
* **База данных:** PostgreSQL 14.
* **Инфраструктура:** Docker, Docker Compose.

## Основной функционал

* Регистрация и JWT-авторизация пользователей.
* Загрузка, скачивание, переименование и удаление файлов.
* Генерация уникальных публичных ссылок для скачивания файлов без авторизации.
* Подсчет количества и размера хранимых файлов.
* Защищенная Панель Администратора для управления пользователями и просмотра их хранилищ.

## Как запустить проект

Проект полностью контейнеризирован. Для запуска на любом компьютере или сервере требуется только установленный Docker.

1. Убедитесь, что Docker запущен.
2. Откройте терминал в корневой папке проекта (где находится файл `docker-compose.yml`).
3. Выполните команду для сборки и фонового запуска контейнеров:
   ```bash
   docker compose up --build -d
Дождитесь окончания сборки (контейнер фронтенда автоматически сгенерирует production-билд и передаст его бэкенду).

Приложение будет доступно в браузере по адресу:

При локальном запуске: http://localhost:8000

При запуске на сервере: http://<ваш-IP>:8000

## Доступ к Панели Администратора
В проекте настроена автоматическая миграция данных. При первом запуске базы данных суперпользователь (администратор) создается автоматически, ручное вмешательство не требуется.

Для входа в систему и доступа к админке используйте следующие данные:

Логин: admin
Пароль: Admin_12345!

(Вы можете изменить этот пароль, удалить пользователя или выдать права администратора другим аккаунтам прямо через интерфейс приложения).
