# MyCloud - Облачное хранилище файлов

Полноценный сервис облачного хранения данных, разработанный в рамках дипломного проекта. Проект представляет собой Single Page Application (SPA) с разделением на микросервисы (frontend, backend, database), упакованные в контейнеры Docker.

## Технологический стек

* Frontend: React 18, Redux Toolkit, React Router, Axios.
* Сборщик: Самостоятельно настроенный Webpack (Babel, CSS/Style Loaders).
* Backend: Python 3.12, Django 6.0, Django REST Framework (DRF).
* База данных: PostgreSQL 14.
* Инфраструктура: Docker, Docker Compose.

## Основной функционал

* Регистрация и JWT-авторизация пользователей.
* Загрузка, скачивание, переименование и удаление файлов.
* Генерация уникальных публичных ссылок для скачивания файлов без авторизации.
* Подсчет количества и размера хранимых файлов.
* Защищенная Панель Администратора для управления пользователями.

## Как запустить проект

Проект полностью контейнеризирован. Для запуска на любом компьютере требуется только установленный Docker Desktop.

Шаг 1. Убедитесь, что Docker Desktop запущен.
Шаг 2. Откройте терминал в корневой папке проекта (где находится файл docker-compose.yml).
Шаг 3. Выполните команду:

docker-compose up --build

Шаг 4. Дождитесь окончания сборки. Приложение будет доступно в браузере по адресу:
http://localhost:3000

## Доступ к Панели Администратора

Так как база данных разворачивается с чистого листа, для доступа к Панели Администратора необходимо создать суперпользователя.

Не останавливая работу сервера, откройте новое окно терминала и выполните команду:

docker-compose exec backend python manage.py createsuperuser

Следуйте инструкциям в терминале (введите логин, email и пароль). После этого вы сможете авторизоваться на сайте под этими данными и получить доступ к админке.
